# 🌤️ Weather App - Real-Time Weather Forecast

A beautiful, responsive weather web application that provides real-time weather data using the OpenWeatherMap API.

## ✨ Features
- 📍 Auto location detection
- 🔍 Search any city by name
- 🌡️ Current weather conditions
- ⏰ 24-hour hourly forecast
- 📅 7-day forecast with detailed views
- 📱 Fully responsive design

## 🛠️ Technologies Used
- Python + Flask (Backend)
- HTML5, CSS3, JavaScript (Frontend)
- OpenWeatherMap API

## 🚀 How to Run

1. Clone the repository
2. Install dependencies: pip install flask requests
3. Get free API key from [OpenWeatherMap](https://openweathermap.org/api)
4. Add your API key to pp.py
5. Run: python app.py
6. Visit: http://localhost:5000
